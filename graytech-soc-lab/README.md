Graytech SOC Analyst Home Lab

Overview

Graytech is a fictional enterprise Active Directory environment built in a home lab for SOC analyst practice. The lab is designed to simulate a small company network with users, departments, security groups, file shares, and Windows security events.

Lab Goals

- Build hands-on experience with Active Directory
- Practice identity and access management concepts
- Generate and investigate Windows security events
- Document SOC-style investigations
- Create portfolio-ready cybersecurity project documentation

Environment

- Domain: graytech.local
- Domain Controller: Windows Server
- Active Directory Domain Services
- 100 fictional employee accounts
- 15 departments
- Department-based security groups
- SMB file shares
- NTFS permissions using group-based access control

Skills Demonstrated

- Active Directory administration
- User and group management
- OU structure design
- AGDLP-style permission modeling
- SMB share and NTFS permission configuration
- Windows event log investigation
- SOC analyst documentation
- Incident response reporting

Project Status

- Active Directory foundation deployed
- 100 fictional users created
- 15 department shares created
- Security group model implemented
- Detection and investigation scenarios in progress
